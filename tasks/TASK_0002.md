Using this knowledge and access, I would like you to carry out the following weekly task

- Query firestore fixtures_archive table for fixtures that were archived since last run (archivedAt)
- Take a sample of Max five games, ensuring the ones you pick have an inner evaluation object

The evaluation object contains three inner objects:
predicted
actual
correct

Predicted contains:
bttsPick (Y/N) - Both Teams to Score?
over25Pick (Y/N) - Over2.5 goals?
resultPick (H/D/A) - Home team win, Away team win, Draw

Actual contains:
hg: Number of Home goals
ag: Away goals
btts: Did both teams score
over25: Was there more than 2.5 goals
result: Who won the match?

Correct contains:
btts: Did I predict Both teams to score correctly?
over25: Did I predict over 2.5 goals correctly?
result: Did I predict the match result correctly?

The fixtures_archive object contains an id which ties it back to fixture_details

Fixture details contains over information such as form, odds, xG data etc

This fixture id can be used to query the sportsmonks api
